El problema es que hay dos animaciones independientes: el ciclo automático de cambio de portada (8s) y la animación visual del libro (page-turn). Quieres que:

    El libro esté "cerrado" mostrando una portada única de "Biblioteca Cantaribeña"

    Cada vez que se abre/cierra (con el efecto page-turn), muestre una nueva portada real

    La sincronización sea perfecta: el cambio de imagen ocurra DURANTE el giro, no en intervalos fijos

🎯 Solución: Libro Sincronizado "Abrir → Cambiar → Cerrar"
1. Nueva Lógica de Sincronización

Flujo corregido:
text

ESTADO INICIAL → [Libro cerrado, mostrando portada fija "Biblioteca Cantaribeña"]
    ↓ (cada 8 segundos o al hacer clic)
ANIMACIÓN INICIA → [Libro comienza a abrirse, sigue mostrando portada fija]
    ↓ (a los 50% de la animación, cuando el libro está "de canto")
CAMBIO SILENCIOSO → [Mágicamente se cambia a portada real, usuario no lo ve]
    ↓ (animación continúa)
LIBRO SE CIERRA → [Ahora muestra la nueva portada real]
    ↓ (pausa de 8 segundos)
REPETIR...

// SÓLO SE EJECUTA EN EL CLIENTE
if (typeof window !== 'undefined') {
  document.addEventListener('DOMContentLoaded', () => {
    const book3d = document.getElementById('book3d');
    const frontCover = document.getElementById('book-front-cover');
    const backCover = document.getElementById('book-back-cover');
    const currentSpan = document.getElementById('current-cover');
    const totalSpan = document.getElementById('total-covers');
    
    if (!book3d || !backCover) return;
    
    // Obtener array de portadas
    const covers = JSON.parse(backCover.dataset.covers || '[]');
    if (covers.length === 0) return;
    
    let currentIndex = 0;
    const totalCovers = covers.length;
    let isTurning = false;
    const TURN_INTERVAL = 8000; // 8 segundos entre giros
    
    if (totalSpan) totalSpan.textContent = totalCovers;
    
    // FUNCIÓN PARA REALIZAR UN GIRO COMPLETO
    function performBookTurn() {
      if (isTurning) return;
      isTurning = true;
      
      // 1. Añadir clase de animación
      book3d.classList.add('book-turning');
      
      // 2. En el punto medio del giro (50%), cambiar la portada SILENCIOSAMENTE
      setTimeout(() => {
        // Actualizar índice
        currentIndex = (currentIndex + 1) % totalCovers;
        
        // Cambiar la imagen de la cara trasera
        backCover.src = covers[currentIndex];
        backCover.alt = `Portada ${currentIndex + 1} de la biblioteca`;
        
        // Actualizar contador
        if (currentSpan) currentSpan.textContent = currentIndex + 1;
      }, 800); // 800ms = 50% de 1600ms (duración total de la animación)
      
      // 3. Al terminar la animación, remover la clase y resetear
      setTimeout(() => {
        book3d.classList.remove('book-turning');
        isTurning = false;
      }, 1600);
    }
    
    // INICIAR CICLO AUTOMÁTICO
    let turnInterval = setInterval(performBookTurn, TURN_INTERVAL);
    
    // CONTROL MANUAL AL HACER CLIC
    book3d.addEventListener('click', () => {
      clearInterval(turnInterval);
      performBookTurn();
      // Reiniciar intervalo después del giro manual
      setTimeout(() => {
        turnInterval = setInterval(performBookTurn, TURN_INTERVAL);
      }, 1600);
    });
    
    // EFECTO HOVER (solo rotación leve)
    book3d.addEventListener('mouseenter', () => {
      if (!isTurning) {
        book3d.style.transform = 'rotateY(-5deg) rotateX(2deg)';
      }
    });
    
    book3d.addEventListener('mouseleave', () => {
      if (!isTurning) {
        book3d.style.transform = 'rotateY(0deg) rotateX(0deg)';
      }
    });
    
    // INICIALIZAR CONTADOR
    if (currentSpan) currentSpan.textContent = 1;
  });
}
</script>

4. Script Mejorado para Descargar Portadas (Opcional pero Recomendado)
typescript

// scripts/process-covers.ts
import fs from 'fs';
import path from 'path';
import { parse } from 'csv-parse/sync';
import https from 'https';

interface BookCover {
  isbn: string | null;
  title: string;
  originalUrl: string;
  localUrl: string;
  hasCover: boolean;
}

async function downloadImage(url: string, filepath: string): Promise<boolean> {
  return new Promise((resolve) => {
    https.get(url, (response) => {
      if (response.statusCode === 200) {
        const fileStream = fs.createWriteStream(filepath);
        response.pipe(fileStream);
        fileStream.on('finish', () => {
          fileStream.close();
          resolve(true);
        });
      } else {
        resolve(false);
      }
    }).on('error', () => resolve(false));
  });
}

async function processCovers() {
  const CSV_PATH = path.join(process.cwd(), 'librería-cantaribeña.csv');
  const COVERS_DIR = path.join(process.cwd(), 'public', 'covers');
  const OUTPUT_PATH = path.join(process.cwd(), 'src', 'data', 'bookCovers.json');
  
  // Crear directorios si no existen
  if (!fs.existsSync(COVERS_DIR)) fs.mkdirSync(COVERS_DIR, { recursive: true });
  if (!fs.existsSync(path.dirname(OUTPUT_PATH))) {
    fs.mkdirSync(path.dirname(OUTPUT_PATH), { recursive: true });
  }
  
  // Leer CSV
  const csvContent = fs.readFileSync(CSV_PATH, 'utf-8');
  const records = parse(csvContent, { columns: true, skip_empty_lines: true, bom: true });
  
  const bookCovers: BookCover[] = [];
  let downloaded = 0;
  
  for (const book of records) {
    const isbn = book.ean_isbn13?.toString().trim().replace(/-/g, '');
    const title = book.title || 'Libro sin título';
    
    if (isbn && isbn.length === 13) {
      const originalUrl = `https://covers.openlibrary.org/b/isbn/${isbn}-L.jpg`;
      const localFilename = `${isbn}.jpg`;
      const localPath = path.join(COVERS_DIR, localFilename);
      const localUrl = `/covers/${localFilename}`;
      
      // Intentar descargar
      const success = await downloadImage(originalUrl, localPath);
      
      if (success) {
        downloaded++;
        bookCovers.push({
          isbn,
          title,
          originalUrl,
          localUrl,
          hasCover: true
        });
        console.log(`✅ Descargada: ${title}`);
      } else {
        // Si falla la descarga, usar URL original
        bookCovers.push({
          isbn,
          title,
          originalUrl,
          localUrl: originalUrl, // Usar URL remota como fallback
          hasCover: false
        });
        console.log(`⚠️  Usando remota: ${title}`);
      }
    } else {
      // Sin ISBN válido
      bookCovers.push({
        isbn: null,
        title,
        originalUrl: '',
        localUrl: '/images/library-cover.svg',
        hasCover: false
      });
      console.log(`📄 Sin ISBN: ${title}`);
    }
  }
  
  // Guardar JSON con rutas locales
  fs.writeFileSync(OUTPUT_PATH, JSON.stringify(bookCovers, null, 2));
  
  console.log('\n📊 RESUMEN FINAL:');
  console.log(`   Total libros procesados: ${records.length}`);
  console.log(`   Portadas descargadas: ${downloaded}`);
  console.log(`   Portadas remotas: ${bookCovers.filter(b => !b.hasCover && b.isbn).length}`);
  console.log(`   Sin portada: ${bookCovers.filter(b => !b.isbn).length}`);
  console.log(`\n💾 JSON guardado en: ${OUTPUT_PATH}`);
  console.log(`📁 Portadas en: ${COVERS_DIR}`);
}

// Ejecutar
processCovers().catch(console.error);

7. ¿Qué Ocurrirá Ahora?

    Libro cerrado: Siempre mostrará el diseño SVG "Biblioteca Cantaribeña"

    Cada 8 segundos: El libro hará un giro completo (160 grados)

    En el punto medio del giro: Cambiará silenciosamente a una portada real

    Al finalizar el giro: El libro se cierra mostrando la nueva portada real

    El ciclo se repite: Mostrando una portada diferente en cada giro

Ventajas de esta solución:

    ✅ Sincronización perfecta entre animación y cambio de contenido

    ✅ Portada fija de biblioteca cuando está "cerrado"

    ✅ Portadas reales solo se muestran DURANTE/DESPUÉS del giro

    ✅ Mejor rendimiento si descargas las imágenes localmente

    ✅ Efecto más realista de "hojear un libro físico"
